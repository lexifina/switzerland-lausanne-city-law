# Art. 126 – Exceptions
Ne peuvent faire l’objet d’une demande de référendum :
1. les nominations et les élections ;
2. les décisions qui concernent l’organisation et le fonctionnement du Conseil ou ses rapports avec la Municipalité ;
3. le budget pris dans son ensemble ;
4. la gestion et les comptes ;
5. les emprunts ;
6. les dépenses liées ;
7. les décisions qui maintiennent l’état des choses existant (article 107 LEDP).
