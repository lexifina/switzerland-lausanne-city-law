# Art. 4 – Règle générale dans les espaces verts
1 En l’absence des signaux prévus à l’article 7, les chiens peuvent être laissés libres dans les espaces verts.
2 Il est interdit d’y laisser les chiens :
a) importuner les usagers ;
b) pénétrer sur les pelouses, parterres, massifs, sablières et terrains destinées aux jeux, les souiller ou les endommager ;
c) se baigner dans les bassins et les fontaines ;
d) poursuivre les autres animaux.
